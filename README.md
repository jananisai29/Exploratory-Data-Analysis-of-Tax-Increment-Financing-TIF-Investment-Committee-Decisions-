# 📊 **EXPLORATORY DATA ANALYSIS OF TAX INCREMENT FINANCING (TIF) INVESTMENT COMMITTEE DECISIONS**

# 🎯 **OBJECTIVE**

The primary objective of this project is to perform **Exploratory Data Analysis (EDA)** on the **Tax Increment Financing (TIF) Investment Committee Decisions** dataset to identify funding patterns, investment trends, and committee decisions.

### 📌 **OBJECTIVES**

- 📖 Study the TIF Investment Committee Decisions dataset.
- 🧹 Clean and preprocess the dataset.
- 📈 Identify trends and patterns in investment decisions.
- 📊 Visualize important variables using charts and graphs.
- 💰 Analyze approval decisions and funding outcomes.
- 💡 Generate meaningful insights and recommendations.
